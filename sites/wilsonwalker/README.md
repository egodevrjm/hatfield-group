# WilsonWalker website

Standalone static website for the fictional WilsonWalker LLC.

Preview with `ruby -run -e httpd . -p 4174` and open `http://127.0.0.1:4174/`.

The public copy is derived from the WilsonWalker company bible. It intentionally excludes private valuations, staff counts, archive locations, access classes and reserved-matters detail. Contact uses the reserved `.example` domain.

The expanded site contains 12 individual Rosie Walker album pages, a filterable catalogue, the locked Homer Wilson credit ledger, the confirmed songwriting/placement register, division pages, archive access and enquiries. The committed catalogue is the public release derived from the private canon workspace.

The `assets/` directory contains original fictional archive imagery and 12 generated fictional album covers. No cover reproduces real album artwork or a real artist likeness.
