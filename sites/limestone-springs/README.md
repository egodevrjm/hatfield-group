# Limestone Springs website

Standalone static website for the fictional Limestone Springs Beverage Co., with an individual detail page and original pack image for every one of the 16 products in `../03_HATFIELD_GROUP/data/limestone_products.csv`, plus recipe and source pages.

Pages are regenerated by `https://hatfield-group.vercel.app/build.mjs`. Preview with `python3 -m http.server 4177 --bind 127.0.0.1`.

Public copy is derived from the company bible. It avoids unsupported health claims, false barrel-water claims and private financial detail.
